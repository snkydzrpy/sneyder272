## Proyectos destacados

### 🚲 [CicloRoto Vial](https://github.com/snkydzrpy/ciclorotocali)
**Análisis de siniestralidad vial y trazabilidad de datos públicos en Cali.**

Proyecto desarrollado en el contexto de una hackathon para explorar dónde se concentran los registros de siniestros con lesionados y qué puede verificarse con los datos públicos disponibles.

- Procesamiento de **51.236 registros** correspondientes a 2016–2025.
- Normalización y resolución de direcciones a intersecciones.
- Ranking con estimación Gamma–Poisson (empirical Bayes) e intervalos de confianza del 95 %.
- Aplicación en Streamlit, pruebas automatizadas y pasos de reproducción documentados.
- Auditoría de trazabilidad: distingue entre una relación no encontrada y una conclusión que los datos no permiten demostrar.

**Importante:** es una herramienta exploratoria basada en registros históricos; no predice accidentes ni sustituye una auditoría vial.

### 🦅 BirdAI — monitoreo acústico e identificación de aves
**Pipeline de procesamiento de audio con BirdNET.**

Proyecto académico desarrollado en equipo para conectar la captura de audio desde una aplicación web con un flujo remoto de procesamiento.

- Integración de Firebase Authentication, Storage y Firestore.
- Worker en Python para validar y preparar audio con FFmpeg/FFprobe.
- Identificación mediante BirdNET y almacenamiento de estados y resultados.
- Automatización del procesamiento mediante servicios de Firebase y Google Cloud.

El repositorio de implementación es privado. La descripción pública se limita a la arquitectura y los aportes que se pueden compartir; no se publica código ni información protegida.
